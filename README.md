# Random Password Generator

## Objective
The objective of this project is to create a Random Password Generator using Python that generates secure and random passwords based on the user's selected character types.

## Features
- Accepts password length from the user.
- Minimum password length is 8 characters.
- Allows selection of at least two character types.
- Supports:
  - Letters
  - Numbers
  - Special characters
- Generates a random password.
- Provides an option to generate another password.
- Handles invalid input using error handling.

## Technologies Used
- Python
- Jupyter Notebook
- string module
- random module

## How It Works
1. Enter the required password length.
2. Select at least two character types.
3. The program creates a character pool based on the selection.
4. A random password is generated and displayed.
5. The user can generate another password if required.

## Example

### Input
- Password Length: 12
- Character Types: 123
- Regenerate: yes

### Output
The program displays a generated password and, if requested, a new password.

## Conclusion
This project demonstrates the use of Python input handling, conditional statements, sets, string operations, random password generation, and exception handling.
